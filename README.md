# Gemini Trading Suite

Next.js application that turns trading research prompts into operating reports generated by Google Gemini. The user enters only a stock name or ticker and selects a prompt type: the backend automatically retrieves metrics from Yahoo Finance and adds Yahoo/TradingView links for verification. The app includes 12 workflows: strategy generation, backtesting, risk/reward, market regime, multi-factor strategy, optimization, portfolio construction, trade setup, Monte Carlo simulation, drawdown analysis, macro strategy, and alpha/edge detection.

## User flow

1. Enter a stock name or ticker.
2. Choose one of the research prompt types.
3. Generate the report.

No capital, timeframe, risk, notes, or manual metric fields are required in the interface.

## Setup

```bash
npm install
cp .env.example .env.local
# add GEMINI_API_KEY to .env.local
npm run dev
```

Open `http://localhost:3000`.

## Deploy on Vercel

This project is a Next.js app. On Vercel, use the `Next.js` framework preset and let the output directory be handled as `.next`. If the Vercel dashboard is configured with `public` as Output Directory, remove that setting or use the `vercel.json` included in this repository.

Configure these environment variables:

```env
GEMINI_API_KEY=your_key
GEMINI_MODEL=gemini-3.5-flash
```

## Environment variables

- `GEMINI_API_KEY`: Google Gemini API key, required by the server route `/api/gemini`.
- `GEMINI_MODEL`: optional, default `gemini-3.5-flash`.

## Product notes

- The Gemini key stays server-side and is never exposed to the frontend.
- Every report must include an objective investment score from 0 to 100.
- Reports are educational research, not personalized financial advice.
- Accurate backtests require real historical data; the app retrieves market data automatically where possible and asks Gemini to state assumptions clearly.

## Automatic market data

The `/api/market-data` route accepts a stock name or ticker, resolves the symbol through Yahoo Finance, and calculates technical/fundamental metrics over up to 5 years of history: price, 1Y performance, CAGR, annualized volatility, max drawdown, SMA 50/200, RSI 14, average volume, market cap, P/E, dividend yield, beta when available, and an objective 0-100 investment score. TradingView is included as a chart-verification link, not as unofficial scraping/API access.
